## A. Market value signals

| Signal | What buyers reward | Birlasoft implication |
|--------|--------------------|------------------------|
| Soft-market speed | Quote faster without silent control concessions | Decision dossier + early gap requests for information, not more forms |
| Attest vs posture | Scan-backed underwriting is table stakes (Coalition / At-Bay / Cowbell) | Gap board is the credibility wedge |
| Stack trichotomy | External signal + catastrophe model + managing general agent telemetry — desks run two or more | Integrate BitSight / CyberCube-class tools; do not rebuild them |
| Shared-vendor risk | Dependent business interruption / concentration (Aon) | Accumulation *alert* at quote time |
| Agentic baseline | Triage at intake, not chat-that-waits | Orchestrated stages + human-in-the-loop bind |

**Proof-of-concept sell:** faster disciplined selection. **Do not sell:** “next Coalition.”

## B. Agentic architecture (ahead of curve)

**Ahead in 2026** = specialist agents + decision orchestrator + human-in-the-loop cite-back — not a single large language model on a form (WNS, DeNexus, AIG / Lexington-style narratives).

| Horizon | State | Our target |
|---------|-------|------------|
| Horizon 1 | Copilot on a form | Easy demo; easy dismiss |
| **Horizon 2** | Orchestrated agents + human-in-the-loop | **Proof of concept should look like this** (mocks acceptable) |
| Horizon 3 | Continuous posture + claims / incident-response learning | Later roadmap / partners |

**Spine:** intake → gap / signal → appetite → tier → book alert → human-in-the-loop decide → dossier / audit → policy administration system.

**Now:** stage roles, explainability, underwriter override, mock ports, swappable appetite.  
**Later:** continuous monitoring, catastrophe portfolio brain, incident-response learning loop, automatic appetite-rule proposals.

**Claim:** decision orchestrator + cyber control-gap spine clients personalize — not chat-only, not an insurance-plus-security carrier stack.
