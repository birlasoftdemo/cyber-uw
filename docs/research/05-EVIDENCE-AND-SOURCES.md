## 1. How to read this file

### Confidence labels

| Label | Meaning |
| --- | --- |
| **Known** | Publicly observable fact or named source statement |
| **Estimated** | Inference / directional judgment from multiple signals |
| **Speculative** | Scenario or unproven forecast |

### Evidence grades (pain / quote level)

| Grade | Meaning |
| --- | --- |
| **A** | Named survey, major broker/reinsurer, regulator/primary law, peer-reviewed |
| **B** | Named practitioner / reputable industry publication with attribution |
| **C** | Vendor / insurtech blog or marketing-adjacent (useful language; commercial bias) |
| **C*** | Expert-operator with product agenda (e.g. cyber MGA blog)—use carefully |
| **C — verify** | Numeric claim that should be re-checked before external pitching |

### Integrity rules

- This pack is **not** an official Gartner report and does not use proprietary Gartner data.  
- **No primary underwriter interviews** yet — do not present secondary paraphrases as Capgemini/Birlasoft client truth.  
- Syndicated “cyber underwriting platform TAM” figures that approach premium-pool scale should be treated as **unreliable for software planning**.  
- Prefer **ranges / directional language** over invented precision.
