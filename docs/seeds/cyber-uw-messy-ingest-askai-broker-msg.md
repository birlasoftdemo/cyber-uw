# Seed: messy ingest + Ask AI + broker messaging

## Idea

After the guided questionnaire happy path is live, expand the workbench with:

1. **Messy ingest fallback** — PDF / email / portal dumps mapped into the same carrier-custom field board (parity path when brokers will not use the form).
2. **Ask AI check** — field-level assist on the underwriter board (not a silent attest).
3. **Broker messaging** — message broker highlighting a specific field (completeness / clarification loop).

## Why deferred

- Day-one differentiation for the buyer starts with structured attestations + dossier control surface + referral bookmarks.
- Research: intake automation alone does not differentiate; attest-vs-signal is the wedge — these features support that loop but are not the first ship.

## Trigger signals

- Pilot MGA brokers adopt guided form OR refuse and stay on PDF (forces messy ingest priority).
- Underwriters ask for AI assist on cite-back / consistency before external signal connectors exist.
- Referral queue stalls waiting on broker answers → messaging becomes blocking.
