# Sketch 002: Risk Analysis evidence

## Design Question

How should **spatial market** vs **ledger capacity** + a **shared cite panel** feel on Risk Analysis?

## Winner

**A: Split stage body** — left/top market as comparative peer space; right/bottom capacity as ledger (limit / ALE / adequacy). One shared right-edge cite slide-in from either region.

## How to View

```bash
open .planning/sketches/002-risk-analysis-evidence/index.html
```

## Variants

- **A: Split stage body** — Market comparative space beside capacity ledger; shared cite panel ← **winner (default for desk)**
- **B: Stacked bands** — Full-width market band above full-width capacity ledger; same cite chrome
- **C: Dense desk** — Adjacent instrument panes (plot vs table) with stronger spatial contrast; identical calm palette

## What to Look For

- Spatial distinction readable without color-coding good/bad (no emerald/amber cheerleading)
- Market reads as comparative space; capacity reads as ledger / limit math
- Cite panel is a source trail only — not a KPI parking lot
- Same panel chrome whether market or capacity opened it
