# Cyber stage UX + dual demo spines

## Decisions

### Hybrid chrome
- **Guided agentic journey:** one job per stage, one primary Proceed CTA, progressive focus on the current stage.
- **Polished workbench:** denser UW desk feel on cards + stepper — not a stripped wizard.

### Advance + sign-off
- **Every stage advances only when the UW clicks Proceed** (no silent auto-advance).
- **Extra HITL sign-off** where AI did work: ingest, risk/signal analysis, Gap board resolve/refer — human owns judgment before Proceed unlocks.

### Design reference
- Insurance/reinsurance submission underwriter is a **feel target** (confidence, craft, motion hierarchy) — **not** a literal pattern/component port.
- Cyber keeps its own stage jobs: Intake → Verify (attest vs signal) → Tier → Book → Decide → PAS coded.

### Dual demo spines (same stage chrome)
1. **Broker outtake spine:** Manage Submissions — create form → dispatch → returned → Proceed to Closure → staged journey → coded (PAS sync).
2. **UW desk spine:** Workbench — open queued case → Proceed through stages → coded.
